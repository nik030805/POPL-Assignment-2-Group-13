# S2 prompts (word for word, in the order they were sent)

## Prompt 1
Implement my-length, my-map and an initial version of insert-if-short in id_q4.rkt. The function must recursively insert x at the front of every list whose original top-level length is less than n, including the top-level list and empty nested lists. Use only the permitted Scheme built-ins. Explain the recursion.

## Prompt 2
Implement make-inserter(x, len-ok?) as specified in S2. It must return a function that recursively processes nested lists and inserts x whenever the length condition is satisfied. Redefine insert-if-short using make-inserter. Ensure the final file contains only one definition of insert-if-short. Explain closures and higher-order functions.

## Prompt 3
Implement print-insert-result in id_q4.rkt. It must read x, lst and n in order and print only the resulting list followed by a newline. Test all assignment examples, empty lists, n = 0, nesting depth 100 and lists of 10,000 elements. Verify that no forbidden built-ins are used.
